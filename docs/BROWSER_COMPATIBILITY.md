# 浏览器兼容性

| 项目 | Chrome / Edge 桌面版 | Firefox 桌面版 |
| --- | --- | --- |
| Manifest | 共用 MV3 清单与运行文件，分别输出 ZIP | MV3，最低 Firefox 142，独立 Gecko ID |
| 新标签页 | `chrome_url_overrides.newtab` 指向本地 `index.html` | 同一覆盖键与入口 |
| 工具栏 | MV3 service worker 处理点击，调用 `tabs.create({})` | MV3 非常驻背景脚本处理同一点击，通过 `browser` 命名空间调用 |
| 核心代码 | 共享 React、p5、诗库、色库、字库 | 同左 |
| 设置与去重 | 扩展页面的 `localStorage`，有 Web Locks 时跨标签页串行化抽取 | 同左，无 Web Locks 时仍维护最近记录 |
| 网络访问 | 搜索需用户提交。自定义网址远程图标单独启用 | 同左，此外使用 Firefox 内置的可选数据传输权限 |
| 背景下载 | Canvas 与页面渲染为 PNG，再用本地下载链接 | 同左，无下载权限 |
| 本地加载 | 解压包，通过扩展管理页加载目录 | `about:debugging` 临时加载 ZIP，正式安装需 Mozilla 签名 |

Gecko ID 为 `jizhi-enhanced@amy22707.github.io`。早期本地 MV2 使用 `jizhi@example.com`，Firefox 将二者视为不同扩展，本地设置不会自动迁移。正式发布后应保留新 ID。两个 Chromium 包逐文件一致，本地安装时的配置由各浏览器各自保存。

后台脚本只保留既有的工具栏点击功能。清单无浏览历史、书签、下载或主机权限。ZIP 内的脚本、字体和数据均是本地资源。联网图标是图片加载，CSP 只允许执行扩展自己的代码。

## 复测步骤

1. 按 [README](../README.md) 加载对应构建。点击工具栏图标或 Ctrl+T，确认打开几枝。若浏览器要求保留扩展对新标签页的修改，选择保留。
2. 断网打开并刷新若干次，检查诗句、传统色、字体和波浪。切换泡泡、深色、竖排、凤栖、汉字原文和色名设置。
3. 检查播放和暂停、Alt+S 和菜单下载、左右键切换、搜索入口以及常用网址的添加、编辑、关闭和重新加载后的保存。
4. Firefox 测试时先拒绝联网图标和搜索权限，再分别接受并复测。在 `about:addons` 撤销权限后检查相应功能，确认默认无需同意即可使用诗词和色彩。
5. 用开发者工具查看控制台、网络请求及 PNG 是否实际保存。不要只看扩展管理器显示已加载。

自动化命令与实际结果见 [验证记录](test-report.md)。
